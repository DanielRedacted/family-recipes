## Start an import

Open a folder (or the home page) and tap the **+** button. Pick one of:

- **From a web address…** to paste the address of a recipe page.
- **From a file (PDF, Word, photo…)…** to choose files.
- **Paste recipe text…** to paste a recipe you copied from an email or a message.

The new recipe goes into the folder you started from. You can change it under **Save into** on the import page, or on the review screen.

You need editing rights to import. If the page says importing needs editing rights, ask whoever looks after the Mac to set a family PIN, then sign in again with it.

## Web pages

Paste one address, or several (one per line), and tap **Get recipe**. Most recipe sites include a tidy copy of the recipe, often with pictures and nutrition, and the app uses it. Otherwise you get the page's main text to tidy up.

## Files and pasted text

Drop files onto the **From a file** box, or tap **Choose files**. Word documents, saved web pages, text files and pasted text are turned straight into a recipe you can review.

PDFs and photos ask first:

- **Keep as a PDF** (or **Keep as a photo**) saves it exactly as it is, with a title and optional tags so you can find it. This is the recommended choice.
- **Convert to an editable recipe** (PDFs only) reads the text out of the PDF into a recipe you can edit, scale and cook from. The layout usually needs some tidying.

A kept PDF can be converted later: open it and tap **Convert to an editable recipe…**. The original file is always kept with the recipe.

## Review before saving

When an import is ready, tap **Review**. You can:

- Fix the name and the folder at the top.
- Edit the recipe on the **Edit** tab, check it on **Preview**, and compare with **Original text**.
- Read the list on the right: **Looks good**, or a few things to check. These are only suggestions; you can save as is and tidy later.
- Tick the **Pictures** to keep and choose one as the **Cover**.

If the app thinks you already have this recipe, a yellow note says so with a link to it.

Tap **Save recipe** to add it, or **Discard** to drop it. The recipe's history records who imported it and where it came from.

## Several at once

Paste several addresses or drop several files and they wait in the **Imports** list, one at a time. Each one can be reviewed as soon as it's ready. If one fails, tap **Try again**, or **Details** to see each step.

## If AI is turned on

When AI has been turned on in the app on the Mac, the review screen also has **Fix with AI**. It suggests a corrected version using the original text, side by side with your draft. Change anything you like, then tap **Use suggestion**, or **Cancel** to keep your draft. AI never changes a recipe unless you accept.
