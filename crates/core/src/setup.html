🍳 Install Recipes as an app

Optional. Recipes already works in this browser with no setup. Do this once on a phone, tablet or computer to add Recipes to the home screen as an app that keeps working while the Mac is asleep. Afterwards it opens securely at https://recipes.local.

This device is already set up. Opening Recipes…

Open Recipes

1. Download the Recipes certificate

Download certificate

It lets this device recognise the Recipes app on your Mac. It only works for recipes.local and home-network addresses, nothing else.

2. Trust it

iPhone or iPad
  1. Open this page in Safari and tap Download certificate, then Allow.
  2. Open the Settings app → tap Profile Downloaded near the top → Install → enter your passcode → Install.
  3. Go to Settings → General → About → Certificate Trust Settings and switch on the Recipes on … certificate.
Android
  1. Tap Download certificate.
  2. Open Settings → Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate (the wording differs a little by phone; search Settings for “CA certificate”).
  3. Tap Install anyway and pick Recipes-CA.crt from Downloads.
Another Mac
  1. Download the certificate and double-click it; it opens in Keychain Access.
  2. Double-click Recipes on …, open Trust, set When using this certificate to Always Trust, close and enter your password.
Windows
  1. Download and open the certificate → Install Certificate… → Current User.
  2. Choose Place all certificates in the following store → Trusted Root Certification Authorities → Finish → Yes.

3. Open Recipes and add it to your home screen

Open https://recipes.local

iPhone/iPad: Share button → Add to Home Screen. Android: ⋮ menu → Install app. It then opens full-screen and keeps working for reading while the Mac is asleep.

To check the certificate is genuine, compare its fingerprint with the one shown in the Recipes app on the Mac (Settings):
